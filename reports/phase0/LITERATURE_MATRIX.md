# Phase 0 literature matrix

Audit date: 2026-08-06. This is the priority corpus for the staged G-FITS
experiments, not a claim of an exhaustive systematic review. “Relevance” is a
G-FITS design interpretation; it is not a result reproduced by this repository.

## Theory-facing conclusions for the staged plan

1. Existing work supports testing source-dependent low-level traces, but not the
   stronger assumption that those traces are additive, resolution-invariant, or
   separable from decoder/VAE/post-processing effects.
2. FITS and the Adobe study motivate a nuisance-control ratio only when the
   nuisance creates shared correlation. E04 must measure that effect; it cannot
   be assumed from the camera literature.
3. G-FITS should target H0 alignment and threshold stability first. An accuracy
   gain without lower NullShift/threshold CV would not support the proposed
   mechanism.
4. Known-source attribution (E06) and unknown-generator detection (E07) are
   distinct claims and require distinct baselines, splits, and rejection rules.
